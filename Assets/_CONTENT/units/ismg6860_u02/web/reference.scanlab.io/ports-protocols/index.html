Common ports & protocols

A quick reference for interpreting the service labels a scanner reports. Port numbers are conventions, not proof: always corroborate with service detection and packet capture.

Well-known & commonly-seen services

PortProtoTypical serviceNotesRisk
443tcpHTTPS / TLS-wrapped appEncrypted web or API service. Common and expected on public hosts.Low
8080tcpAlternate HTTPFrequently an admin panel, proxy, or device diagnostics console. Review carefully when exposed.Review
9100tcpRaw print / JetDirectPrinter or device telemetry. Risky when reachable outside a maintenance segment.High
161udpSNMPManagement protocol. Often reported open|filtered: the scanner cannot always tell a quiet service from a filtered one.Review
22tcpSSHRemote administration. Expected on managed hosts; unexpected exposure is worth noting.Review
N/AicmpEcho / error reportingUsed for host discovery. Commonly filtered by policy, so silence is not proof of absence.Low

No entries match that filter.

A scanner's open, closed, and filtered labels describe the response category observed from packets, not the safety of a service. Confirm anything exposed with service/version detection before you record it as a finding.

Cross-Site Scripting (Reflected)

Confirmed
https://portal.northbridge.com/services/search?q=<input>
CVSS 3.16.1
CWECWE-79
OWASPA03:2021 Injection
Affected Featurecitizen-search
Description

The citizen-search feature reflects the value of the q request parameter back into the response without sufficient output encoding. A crafted value in the query string is returned inside the page and interpreted by the browser.

Reflected cross-site scripting lets an attacker run script in the context of a resident's session when that resident follows a prepared link, which can lead to session or data exposure on a public-facing civic service.

Proof: HTTP Request / Response
GET /services/search?q=test<script>cqxss()</script> HTTP/1.1
Host: portal.northbridge.com

--- response (excerpt) ---
<h3>Results for "test<script>cqxss()</script>"</h3>

The injected value was returned unencoded inside the results heading.
Recommendation

Apply context-aware output encoding when reflecting user input into HTML, and validate / sanitize input on the search endpoint.

Remediation owner: application development team.

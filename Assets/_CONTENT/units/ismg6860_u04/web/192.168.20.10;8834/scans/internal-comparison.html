Reachable from the portal app server, which is itself exposed to public traffic.

Description

The detected Struts branch matches published remote code execution advisories. The management interface is not exposed externally, but it sits one hop behind a public-facing application server, so the public surface and the internal weakness are connected.

Solution

Upgrade Apache Struts to a fixed release, restrict the management interface to maintenance hosts, and monitor for exploitation attempts against the app server.

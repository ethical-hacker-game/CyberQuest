Description

The remote web server exposes a deployment / setup interface that should be removed or restricted after installation. A reachable setup wizard can disclose configuration details and, depending on state, allow reconfiguration of the application.

Solution

Remove the setup routes after deployment, or restrict them to approved maintenance hosts. Confirm the wizard cannot be reached from public networks.
